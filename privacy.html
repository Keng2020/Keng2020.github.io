gmail-mcp – Privacy Policy

gmail-mcp is a personal tool. It is used only by its owner, on the owner's own computer, to read the owner's own Gmail mailbox. It is not offered to the public.

What it accesses

With the owner's consent, the tool requests read-only access to Gmail (gmail.readonly) and the basic profile information needed to confirm which account signed in. It cannot send, modify or delete email.

Where data goes

Email content is fetched directly from Google's API to the owner's computer. Access tokens are stored locally on that computer. No data is collected on any server operated by this project, and nothing is sold or shared with third parties.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
